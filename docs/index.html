ESP32-C3 · Defensive wireless monitoring

Observe the Wi-Fi environment without disrupting it.

Wi-Fi Phantom is a compact ESP32-C3 monitoring project that inventories nearby 2.4 GHz networks, highlights review-worthy changes, and serves a local dashboard without collecting credentials or disconnecting clients.

Device setup

Install from your browser

Connect a supported ESP32-C3 with a data-capable USB cable, approve the serial device, and install the current defensive firmware.

Download firmware View releases

Desktop Chrome or Edge is recommended. The browser will ask you to approve the serial device.

📡 Network inventory

SSID, BSSID, channel, RSSI and advertised security mode are shown in the local dashboard.

👻 Phantom observations

Duplicate SSIDs and changes between scans are flagged for review without automatically declaring a network malicious.

🛡️ Defensive by design

The current firmware does not deauthenticate clients, clone third-party access points, or collect Wi-Fi passwords.

Quick start

01 · CONNECTAttach the ESP32-C3 using a USB data cable.
02 · INSTALLUse the installer above and approve the serial device.
03 · JOINConnect to Wi-Fi-Phantom-Monitor with password phantomsecure.
04 · OBSERVEOpen 192.168.4.1 and use Scan now.
Authorized observation only. Duplicate SSIDs can be legitimate on mesh, extender and enterprise networks. Treat dashboard flags as observations that require context, not proof of a rogue access point.
